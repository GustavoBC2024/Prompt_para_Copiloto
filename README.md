# Prompt para Copiloto

Assistente técnico para desenvolvimento com foco em Python 3.11 + IA.

## Stack

* Python 3.11
* LangChain
* Gemini
* sentence-transformers
* NumPy
* scikit-learn

## Objetivo

Fornecer suporte técnico para:

* análise de código;
* arquitetura;
* integração com IA;
* debugging;
* automações;
* pipelines de embeddings e RAG.

## Estrutura

```text
project/
├── src/
├── tests/
├── data/
├── requirements.txt
└── README.md
```

## Como executar

```bash
pip install -r requirements.txt
python main.py
```

## Funcionalidades

* Assistência técnica
* Explicação de código
* Diagnóstico de erros
* Geração de snippets
* Orientação arquitetural
